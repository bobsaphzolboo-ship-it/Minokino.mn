# Видео стриминг backend — жишээ

## Юу хийдэг вэ
- `/api/movies` — кино жагсаалтыг JSON-оор буцаана
- `/stream/:id` — видеог **HTTP Range** хүсэлтээр хэсэгчлэн дамжуулна (Netflix, YouTube-ийн ашигладаг цөм арга)
- `/player.html` — жагсаалт харуулж, кино дээр дарахад тоглуулдаг жишээ фронтенд

## Ажиллуулах
```bash
npm install
node server.js
```
Дараа нь: http://localhost:3000/player.html

## Анхаарах зүйл
- `videos/` хавтсанд `sample1.mp4`, `sample2.mp4` нэртэй жинхэнэ видео файл байрлуулаагүй тул одоогоор тоглуулахад алдаа өгнө. Туршихын тулд өөрийн эрхтэй жижиг mp4 файлыг тэр нэрээр хийж үзээрэй.
- Жинхэнэ бүтээгдэхүүнд:
  - Видеог шууд оруулахгүй, эхлээд **HLS/DASH** формат руу encode хийж (олон чанараар: 480p/720p/1080p), CDN (жишээ нь Cloudflare, CloudFront) ашиглан дамжуулдаг.
  - Видео файлыг серверийн локал диск дээр биш, S3 гэх мэт object storage-д хадгална.
  - Захиалга шалгах, нэвтрэлт баталгаажуулах middleware энэ `/stream/:id`-ийн өмнө орж, эрхгүй хэрэглэгчийг блоклоно.
